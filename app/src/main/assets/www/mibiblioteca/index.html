¿No se abre la ventana para elegir tu cuenta?

En Brave para Android la ventana de Firebase suele bloquearse. Con el inicio de sesión oficial de Google funciona siempre; solo hay que darle a la app su "ID de cliente" (una vez):

1. Firebase → Authentication → Método de acceso → Google → despliega "Configuración del SDK web" y copia el ID de cliente web (termina en .apps.googleusercontent.com).
2. Google Cloud → APIs y servicios → Credenciales → abre ese cliente ("Web client (auto created by Google Service)") → en Orígenes autorizados de JavaScript agrega → Guardar.
3. Pégalo aquí y toca Guardar.

Se guarda en tu Firestore (solo tú lo puedes leer), no en el código.

Si tienes el servidor de MiBiblioteca (server.js) publicado, pega aquí su dirección. Abre los RAR por ti, entrega los libros y portadas al instante y la app pesa menos en el celular. Si no responde, la app sigue funcionando sola como siempre.

Lee solo la ficha y la carátula de cada libro (unos KB), sin bajar el libro completo cuando el zip lo permite.

¿Cómo cargo más voces?

La app usa las voces instaladas en tu teléfono o computador; el navegador no puede descargar voces por su cuenta.

Android: Ajustes → Sistema (o Accesibilidad) → Idiomas → Salida de texto a voz → motor de Google → ⚙ → Instalar datos de voz → Español (elige Estados Unidos o España y descarga las voces de alta calidad). Luego vuelve aquí y toca "Recargar voces".

Windows: Configuración → Hora e idioma → Voz → Agregar voces. iPhone: Ajustes → Accesibilidad → Contenido leído → Voces.

En Chrome/Edge para computador también aparecen voces "Google" u "Online (Natural)" que suenan mejor.

Instala MiBiblioteca como app y guarda libros en este dispositivo para leerlos sin internet (avión, viaje, sin datos). Lo que leas sin conexión se sincroniza solo al volver la señal.
